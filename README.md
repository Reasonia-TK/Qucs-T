# Qucs-T

熱回路図から定常温度、温度の時間変化、枝ごとの熱流を求める Windows デスクトップアプリです。Qucs-S-Rust の回路図エディタ、自動配線、接続判定をベースにしています。熱解析は内蔵の Rust ソルバーで実行します。

[Windows x64 版 v0.1.0 をダウンロード（ZIP）](https://github.com/Reasonia-TK/Qucs-T/releases/download/v0.1.0/qucs-t-0.1.0-windows-x64.zip)

[ユーザーマニュアル](docs/user-manual.md)

## 起動

```powershell
cargo build --release
.\target\release\qucs-t.exe gui
```

ツールバーの **サンプル** を選ぶと、接触熱抵抗でつながる発熱部品とヒートシンクの回路が開きます。**熱解析…**（F5）を開き、**定常解析** または **過渡解析** を実行します。

サンプルでは発熱量 20 W の定常状態を計算できます。過渡解析の発熱表では、10–100 秒と 150–240 秒に 20 W を加えます。空気への対流と壁面への輻射は別々の枝です。

## Windows 向けインストーラーのビルド

Windows x64 の Rust ツールチェーンと MSVC の C++ ビルドツールを用意し、リポジトリのルートで PowerShell から実行します。

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\package.ps1
```

リリースビルドを実行し、`dist\qucs-t-<バージョン>-windows-x64.zip` を生成します。ZIP には `qucs-t.exe`、インストール・アンインストール用の PowerShell スクリプト、マニュアル、サンプルが入ります。`target\release\qucs-t.exe` をビルド済みなら、上のコマンドの末尾に `-NoBuild` を付けると ZIP の作成だけを実行できます。

インストールするには ZIP を展開し、展開したフォルダーで次を実行します。

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

管理者権限は不要です。既定のインストール先は `%LOCALAPPDATA%\Programs\qucs-t` で、スタートメニューに **Qucs-T** が追加されます。`.qucst` の「プログラムから開く」に Qucs-T を登録するには `-Associate` を、ユーザーの PATH に追加するには `-AddToPath` を付けます。

## 熱回路図を作る

1. 左のパレットから部品を選び、回路図上に配置します。
2. W で手配線、A で自動配線します。L でノード名を付けられます。同名のラベルは同じノードとして計算します。
3. 部品を選択し、右のプロパティで値を変更します。伝導・接触・対流・輻射の図記号は共通です。表示ラベルと計算モデルは独立に変更できます。
4. Ctrl+S で解析設定を含む `.qucst` ファイルに保存します。

| 部品 | 入力 |
| --- | --- |
| 伝導・接触 | 熱抵抗を直接入力 [K/W] |
| 伝導・寸法指定 | 伝熱距離 [mm]、熱流に垂直な断面積 [mm²]、熱伝導率 [W/(m·K)] |
| 対流 | 一定の熱伝達率 [W/(m²·K)]、面積 [m²] |
| 輻射 | 有効放射率、交換面積 [m²]。内部の絶対温度で４乗則を計算 |
| 円筒・軸方向 | 軸長、内半径、外半径 [mm]、熱伝導率 [W/(m·K)]。内半径 0 で中実円筒 |
| 円筒・半径方向 | 軸長、内半径、外半径 [mm]、熱伝導率 [W/(m·K)]。内半径は 0 より大きい値 |
| 熱容量 | 直接入力 [J/K]、または平板・円筒の寸法 [mm、mm²]、密度 [kg/m³]、比熱 [J/(kg·K)]。初期温度は任意 |
| 発熱源 | 定常発熱量 [W]、一定または発熱表 |
| 固定温度 | 境界温度 [°C]。過渡解析では温度表も指定可能 |

円筒の２種類も共通の抵抗記号を使い、プロパティに計算した熱抵抗 [K/W] を表示します。

- **伝導・寸法指定**は、板などの一定断面での一次元伝導を表します。抵抗は `伝熱距離 / (熱伝導率 × 断面積)` です。既存の「伝導」素子では、計算モデルの選択で「伝導」と「伝導・寸法指定」を切り替えられます。
- **円筒・軸方向**は両端面を端子につなぎます。軸長を `L`、熱伝導率を `k`、内外半径を `rᵢ, rₒ` とすると、抵抗は `L / (kπ(rₒ² − rᵢ²))` です。
- **円筒・半径方向**は端子 1 を内面、端子 2 を外面として使えます。抵抗は `ln(rₒ/rᵢ) / (2πkL)` です。多層管は層ごとに一つずつ置き、界面を直列につなぎます。[DOE Heat Transfer Handbook](https://www.energy.gov/documents/doe-hdbk-1012-92vol2)

各抵抗素子は均質な材料の一次元伝導を表します。熱容量素子の「容量設定」で平板または円筒を選ぶと、`密度 × 体積 × 比熱` で求めた容量が表示されます。円筒の内半径を 0 にすると中実円筒の体積になります。

発熱表は `時刻,発熱量` を１行ずつ入力します。先頭の時刻は 0 秒とし、次の行まで発熱量を保持します。定常解析と定常解からの過渡開始には、発熱源ごとの発熱量欄を使います。

固定温度素子で「温度入力」を「温度表」にすると、過渡解析の境界温度を `時刻,温度` の表で指定できます。0 秒から始め、点と点の間は線形補間し、表の最後の温度を保持します。定常解析と定常解からの過渡開始には通常の温度欄を使います。

熱容量のあるノードは共通初期温度（既定 25 °C）か、熱容量のプロパティに指定した初期温度から開始します。熱容量のないノードはその時刻の熱収支を満たす温度になります。定常解析には各熱回路から固定温度境界への経路が必要です。

## 円筒の回路を生成する

ツールバーで **円筒回路を生成…** を選び、寸法、材料、軸方向・半径方向の分割数を指定します。各セルの熱容量とセル間の熱抵抗を配置し、各表面までの伝導抵抗を含む回路を新しいタブに開きます。軸方向の分割数と全層の半径方向分割数の積は最大 256 セルです。

- **片端加熱＋外面対流** を押すと、発熱端と冷却面をまとめて設定できます。「表面条件」では、端面 A・B、内面、外面ごとに断熱・固定温度・発熱・対流・輻射・対流と輻射の併用を選べます。対流・輻射の面積は自動計算し、発熱量は面積に比例して各区間へ配分します。
- **外側に層を追加** で、管壁の外側に断熱材などを追加します。各層の外半径・半径方向分割数・材料を指定します。層間の半径方向抵抗は、境界の両側の材料でそれぞれ計算します。「材料を登録／更新」で保存した材料は、別の円筒にも適用できます。
- 外側の層を選ぶと、**内側の層との接触熱抵抗 [m²·K/W]** を入力できます。0 より大きい値を指定すると、面積当たりの値を区間の界面面積で割って接触素子を配置します。温度結果の `界面…内側` と `界面…外側` で両側の温度を読めます。既定値 0 では両側が同じ温度になります。
- **表面条件**では、面全体の発熱表、固定温度の温度表、対流の流体温度表、輻射先の周囲温度表を指定できます。発熱表の各行は面積に応じて区間へ配分し、次の行まで発熱量を保持します。温度表は入力点の間を線形補間します。定常解析は発熱量と温度の一定値欄を使います。
- 生成した素子と配線は編集できます。表面条件の素子と円筒は同名のネットラベルでつながります。内半径 0 のときは内面を省略します。
- 生成した回路を保存すると、寸法・分割・材料・表面条件も保存されます。この回路で **円筒回路を生成…** を開くと、保存した条件を読み込んで新しいタブに再生成できます。

生成画面の **生成条件のスイープ** では、最外層の厚さ、外面の熱伝達率、両方向の分割倍率を指定できます。定常または過渡解析を連続実行し、最高温度、最大放熱、同じ軸位置・半径にあるセルの最高温度を比較して CSV に保存します。過渡の解析設定は現在の回路図に保存されている値を使います。

## 結果

定常解析ではノード温度と枝の熱流を回路図に表示します。枝の熱流は端子 1 → 端子 2 が正です。過渡解析では表示する温度・熱流を選び、グラフと最高温度、設定温度への初回到達時刻を確認できます。初回到達時刻は記録した点の間を補間します。発熱表の切り替え時刻は切り替え直前と直後の結果を記録します。

**境界の熱流**は境界に逃げる熱を正、境界から入る熱を負として表示します。**熱収支**には発熱源合計、境界からの加熱、境界への放熱、蓄熱速度とその差分を W で表示します。境界に複数の同一温度素子があるときは、同じノードの熱流をまとめます。

条件を比較するときは、解析後に **この結果を比較基準にする** を押し、条件を変えて同じ種類の解析を実行します。別タブの回路も比較できます。最高温度・最大放熱の差と、過渡解析では選択した信号の重ね描きを確認できます。比較基準はアプリの実行中に保持します。

過渡結果で **温度 → 実測温度を重ねる → 実測 CSV を開く…** を選ぶと、計算波形に実測点を重ねられます。CSV は UTF-8 のカンマ区切りで、時刻は秒、温度は °C の数値を使います。見出し行は任意です。複数の計測点がある場合は温度列を選べます。時刻は昇順に並べ、温度が空欄の行は除外します。

実測点にカーソルを合わせると、その測定時刻での「解析 − 実測」の差を確認できます。実測データは開いているタブで再解析後も使えます。`.qucst` には保存されません。

今回の生成機能で作った円筒回路では、解析結果の **温度マップ…** で軸位置・半径ごとの代表温度を表示できます。過渡解析では時刻を選択できます。円筒の比較基準を設定して図中の位置を選ぶと、分割数が異なる場合も、同じ物理位置を含むセルの温度差を表示します。

円筒の測定位置を照合するときは、過渡解析の温度マップで位置をクリックし、**この位置の過渡波形を表示**で対応するセルを選べます。

結果は解析ウィンドウから CSV に書き出せます。CLI では出力ファイルを省略すると JSON を標準出力に返します。

```powershell
.\target\release\qucs-t.exe steady .\examples\heatsink.qucst
.\target\release\qucs-t.exe transient .\examples\heatsink.qucst results.csv
```

## MCP

MCP クライアントから `qucs-t.exe mcp` を stdio サーバーとして起動します。リポジトリの `.mcp.json` はビルド済みの実行ファイルを使います。`qucs-t` を PATH に登録している場合は、次の設定も使えます。

```json
{
  "mcpServers": {
    "qucs-t": {
      "command": "qucs-t",
      "args": ["mcp"]
    }
  }
}
```

相対パスは `QUCS_MCP_WORKDIR` を設定するとそのフォルダーを基準にします。既定は起動ディレクトリの `qucs_work` です。

| 操作 | ツール |
| --- | --- |
| 新規作成・既存回路を開く | `new_thermal_schematic`、`open_schematic` |
| 熱素子の検索・編集・配線 | `list_component_types` に `{"category":"thermal"}` を指定。`get_component_type`、`add_components`、`update_component`、`connect` を使用 |
| 多層円筒の生成 | `generate_thermal_cylinder` |
| 解析条件を読み書き | `get_thermal_settings`、`set_thermal_settings` |
| 定常・過渡解析 | `run_thermal_analysis` の `kind` に `steady` または `transient` を指定 |
| 温度・熱流・熱収支を取得 | `get_thermal_results`、`export_thermal_csv` |
| 円筒の条件を変更して比較 | `run_thermal_sweep` |
| GUI で回路を確認 | `open_gui`、`get_gui_state`、`snapshot` |

例えば `open_schematic` で付属の `examples/heatsink.qucst` のフルパスを指定し、`run_thermal_analysis` を `{"kind":"transient"}` で実行します。`get_thermal_results` に `{"group":"temperature","signal":"発熱部品","at_s":[10,60,100]}` を渡すと、指定時刻の温度を取得できます。生成した円筒では `position_mm: [軸位置, 半径]` でも温度を指定できます。回路を編集した後は再解析してから結果を取得します。

定常値・時系列・座標指定に使える引数は、MCP の `tools/list` に含まれます。[MCP ツール一覧](docs/mcp-tools.md)

ソルバーのテストは `cargo test` で、MCP の検証はビルド後に `python tests/e2e_thermal_mcp.py` で実行できます。ライセンスは GPL-2.0-or-later です。
